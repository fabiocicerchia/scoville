# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through
[GitHub Security Advisories](https://github.com/fabiocicerchia/scoville/security/advisories/new).
If that is unavailable, email the maintainer listed on the
[fabiocicerchia](https://github.com/fabiocicerchia) profile.

You can expect an initial response within 7 days. Once a fix is available it is
released and the advisory is published.

## Supported versions

Only the latest release of `scoville` receives security fixes.
